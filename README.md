# Assignment 2: The Learning Journal

A responsive student portfolio built with HTML and CSS. This is a fresh project because the destination repository was empty. The journal text is illustrative and can be personalized.

## Open the website

Open `index.html` in a browser. No installation or build step is required.

## Assignment requirements

- `index.html` links to `style.css` inside its `<head>`.
- The body has an explicit font, line height, text color, and background.
- The header uses `position: sticky`, `top: 0`, clear text, and a box shadow.
- Navigation links have hover and keyboard focus styles.
- Main content is centered and uses flexbox, with responsive layouts.
- The footer matches the header's colors.

## Additional details

The page includes a skip link, semantic sections, mobile styles, and reduced-motion support. All artwork uses CSS; there are no external assets, scripts, or libraries.

## GitHub Pages

After these files are committed to GitHub, enable Pages in the repository settings and select the branch containing the files and the root folder. GitHub will show the website address when deployment finishes.
